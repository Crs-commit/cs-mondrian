# CS-Mondrian v1.2

本仓库提供方法后处理代码、实验协议、汇总结果、部分图表及参考文献。

- [复现材料与输入说明](00_说明与索引/00_README_复现包说明.md)

- [授权状态](LICENSE_STATUS.md)

SEUMLD、MDPE 的原始数据、标签、预测张量和个体映射不随仓库分发。
Open-Domain 与 Cross-Cultural 的数据许可需分别核对，本包也不分发其预测输入。
研究者须通过原始数据持有者的获取流程取得适当授权。

汇总表可用于核对报告数字；受试者级置信区间与配对检验的独立重算还需要授权输入。
当前包不包含完整基础模型训练流水线，尚未完成干净目录下的端到端复现验证。
恢复的历史汇总表仍包含待修订的 Monte Carlo 零 p 值，详见复现说明。

本版本移除了旧代码 ZIP，并以无父提交的公开子集建立发布历史。
该操作不撤回此前已下载的副本，也不保证托管平台立即清除旧对象或缓存。
