## 四、输入数据规范（自备）

核心后处理读取**基础预测器输出的预测张量**和单位映射；部分外部诊断还需要本地语料或派生表。完整训练流水线不随本包提供。
自备输入时应满足以下字段规范：

| 字段 | 说明 |
|---|---|
| `probs` | 测试集 lie 后验概率（float32/64） |
| `labels` | 测试集真实标签（0=truth, 1=lie） |
| `preds` | 测试集预测标签 |
| `calib_probs` / `calib_labels` | 校准集概率与标签 |
| `val_probs` / `val_labels` | 验证集概率与标签 |
| `test_subject_ids` | （仅外部数据集）测试集受试者/单位 ID |

数据规模约定：2 config（text / audio）× 5 fold × 5 seed；
中文数据集为 SEUMLD 与 MDPE，外部为 Open-Domain 与 Cross-Cultural。
Cross-Cultural 存在 v1 / v2 两个校准版本，用法见 §六。

## 五、重跑命令

```bash
# 环境：Python 3.11，numpy / pandas / scipy

# 1) 核心严格重算
cd 03_代码/01_核心严格重算
python strict_recompute.py

# 2) Singh 对照臂（中文 ~220s，外部 ~130s）
cd ../02_Singh对照臂_新实验
python singh_arm_recompute.py
python fix_stats_eps_hum.py
python singh_external_recompute.py
python singh_self_check.py          # 自检，应全部 PASS

# 3) 替代调度消融
cd ../03_替代调度消融_新实验
python schedule_ablation_recompute.py
python schedule_ablation_external.py
python schedule_ablation_self_check.py
```

运行前必须按各脚本当前的输入路径配置准备授权文件。核心严格重算读取
`DECEPTION_DATA_ROOT`、`SUBJECT_MAP_PATH`、`STRICT_PROJECT_ROOT`；
Singh 脚本仍使用 `INTEGRATION_ROOT` 下的历史相对目录布局。
并非所有脚本都读取 `CS_MONDRIAN_ROOT`。以上命令是入口说明，不代表干净目录下已验证一键复现。

## 八、可移植性说明

路径脱敏与可运行性是两项不同检查。部分脚本仍依赖历史相对目录或占位配置，
需按输入路径设置后运行。受支持的后处理流水线已在授权本地输入上通过空输出目录重算，详见 `MONTE_CARLO_REPRODUCTION.md`。

`strict_subject_aggregated_stats.csv` 不含个体标识，已与 Singh 和调度消融的四份比较表一并重算。
Monte Carlo 检验使用 `(b+1)/(B+1)`，B=10000；不是将零替换为任意小数。
本次不宣称已完成基础模型训练或全部历史外部实验的端到端复现。

代码授权状态见根目录 `LICENSE_STATUS.md`。
